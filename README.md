# Celestia Noire

A modern, responsive website built with HTML, CSS, and JavaScript.

## 🚀 Features

- Responsive design
- Smooth animations with AOS (Animate On Scroll)
- Owl Carousel for sliders
- Font Awesome icons
- Bootstrap framework
- Modern UI/UX

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom styling with Bootstrap
- **JavaScript** - Interactive functionality
- **Libraries:**
  - Bootstrap 5
  - Owl Carousel
  - Font Awesome 6
  - AOS Animation

## 📁 Project Structure

```
Celestia Noire/
├── index.html          # Main HTML file
├── assets/             # Images and media
├── Css/                # Stylesheets
│   ├── bootstrap.min.css
│   ├── header.css
│   ├── owl.carousel.min.css
│   └── style.css
├── Js/                 # JavaScript files
│   ├── bootstrap.min.js
│   ├── owl.carousel.min.js
│   └── script.js
└── favicon-clas/       # Favicon assets
```

## 📌 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rmsuvajit18/Celestia-Noire.git
   ```

2. **Open in browser:**
   - Navigate to the project folder
   - Open `index.html` in your preferred browser
